# lab5

Lab 5: Build and Query the Peer Tutoring Hub Database (IS 6465)

- `tutoring.sql`: every SQL statement for Parts 1 to 5, labeled with comments
- `tutoring.db`: the SQLite database the script builds
- `lab5-notes.md`: answers, SQL, and query output

Rebuild the database from the project folder:

```bash
sqlite3 tutoring.db < tutoring.sql
```

The PHP application files are the unchanged Peer Tutoring Hub starter files from the earlier labs.
